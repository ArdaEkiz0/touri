# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting ("Security" tab > "Report a vulnerability") on this repository.
Include the affected version, reproduction steps and the impact you observed.

We aim to acknowledge reports within 5 business days and to ship a fix or mitigation
for confirmed issues as quickly as practical. Please allow time for a fix before any
public disclosure.

## Scope

touri runs locally and handles credentials, shell access and optional computer control.
Reports about secret exposure, approval or sandbox bypass, path traversal, and the
local HTTP/WebSocket surface are especially welcome.
